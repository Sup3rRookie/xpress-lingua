# XpressLingua

Version: 0.20.1

Tech stack: Expo SDK 57 (React Native 0.86, TypeScript), ts-fsrs, MeloTTS (pre-rendered audio), expo-speech fallback, sql.js + fflate for Anki import, AsyncStorage + IndexedDB, GitHub Pages deployment.

A speaking-first language trainer for Mandarin and Japanese. Cards cannot be passed silently: the learner says the answer out loud before flipping. Reading and writing are out of scope by design.

Live app: https://sup3rrookie.github.io/xpress-lingua/

Progress is stored per browser. Use Back up / Restore (You tab) to move between devices.

## Features

- Speak-to-flip flashcards with FSRS scheduling (long-term intervals, no same-day repeats)
- Two built-in decks: Survival (120 phrases, 10 scenario chapters with sequential unlock) and HSK Ladder (1,156 words, levels 1-4, selectable starting level)
- Example sentence with audio on every card back. Sources: Tatoeba (CC-BY, attributed) plus hand-written sentences for corpus gaps
- Episode mode: hands-free listen-and-repeat. Each line plays the native audio, leaves a silence sized to how long that line actually took, speaks the English meaning, then repeats the line slowly. The meaning stays hidden until it is spoken, so the first pass is a listening test rather than reading
- Travel phrases in both languages: 381 scenario sentences (173 Mandarin, 208 Japanese) across 8 situations, each reviewed by two independent native speakers. Listen to the native line, repeat it aloud, save any line to check with a native-speaker friend
- 16,927 pre-rendered audio clips, MeloTTS voice. This includes the English meanings used by Episode mode, so no part of a session depends on the browser's own speech synthesis, whose quality varies by machine. Mandarin clips are verified by Whisper transcription or human review; Japanese clips are screened by a peak-volume gate. Clips that fail verification, or tokens the engine cannot voice (some isolated Japanese single-kanji/kana and counter words), fall back to browser TTS
- Slow replay for shadowing on Japanese words and example sentences, and on Mandarin travel phrases. Slow clips are a slower re-synthesis rather than slowed playback, so tone and pitch accent stay correct
- Tone-colored pinyin (Pleco convention), hanzi shown small and optional
- Pitch contour comparison: records the learner, plots their F0 curve against the native clip, scores tone shape match (YIN tracking, register-invariant)
- Pronunciation check via browser speech recognition
- Tone Trainer: tone quiz, minimal pairs, shadowing reps
- Sentence library plus a generator that builds practice sentences from learned words only
- Anki .apkg import: in-browser SQLite parsing, automatic field mapping, bundled audio stored in IndexedDB
- Browse screen: full word list per level with search and sentence preview
- Daily pace setting (5/8/15/25 new cards per day) with a keep-going override
- Progress backup and restore as JSON

## Content pipeline

Deck data is generated by scripts, not written by hand:

- `scripts/build-hsk-deck.js` builds the HSK deck from the complete-hsk-vocabulary dataset (MIT)
- `scripts/build-hsk-examples.py` matches each word to a Tatoeba example sentence and generates pinyin
- `scripts/render-zh-melo.py` renders sentence audio with MeloTTS
- `scripts/render-zh-words-v2.py` renders word audio with verification: each clip is transcribed by Whisper and must match the expected pinyin syllable sequence before it is accepted. Short words that fail as single utterances are rendered as the word spoken twice
- `scripts/render-ja.py` renders Japanese audio (survival phrases, JLPT words, example sentences) with MeloTTS as mp3, with a peak-volume gate that drops silent synthesis. `--slow` renders the slower `-slow` companion clips. `scripts/prune-silent-ja.py` scans existing clips and records unvoiceable ids in `src/data/ja-audio-suspect.json` so those cards fall back to browser TTS
- `scripts/render-en.py` renders the English meanings spoken by Episode mode (`--speaker` selects the accent, default EN-AU)
- `scripts/build-ja-travel-sentences.js` assembles the Japanese travel deck from the generated per-scenario files plus `scripts/ja-travel-fixes.json`, which records every native-review correction and added line with its reason
- `scripts/verify-audio.py` audits existing clips against expected pinyin

GPU is used automatically when available. All scripts are resumable and show tqdm progress.
